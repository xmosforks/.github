## XMOS forks and mirrors

This organisation hosts forks and mirrors of third-party projects used in the XMOS software ecosystem. These are kept separate from XMOS-developed projects to make their origin clear.

----

**Looking to develop with XMOS? Start at [github.com/xmos](https://github.com/xmos)** for XMOS libraries, examples, tools and developer resources.
